# Scribe Blog

This is a full stack blog-site written in Typescript and built with Node JS and Express, created as part of the Odin Project's Node JS course.

## Features
  - JWT-based authentication with signup, login, and logout
  - Rich text post creation via TinyMCE editor
  - Publish and unpublish blog posts
  - Nested comment threading w/ soft delete feature
  - User profiles with follow/unfollow and follower counts
  - User search with live dropdown results
  - Community tab that displays users followed and following
  - Route protection for both authenticated users and site guests

## Concepts Illustrated
  - Full stack Typescript across frontend and backend
  - Rest API design with Express
  - Relational data models with self-referential relations (Comment Trees, Following)
  - Shared type definitions across components
  - Context-based global auth state with React Context Api
  - Monorepo deployment between Cloudflare Pages and Render

## Technologies
  - Node.js (Runtime)
  - Express (Node Framework)
  - React + Vite (Frontend + Bundler)
  - Typescript (Language)
  - Prisma (ORM)
  - PostgreSQL (Database)
  - TinyMCE (Rich Text Editor)
  - JWT + bcryptjs (Authentication)
  - Cloudflare pages (Frontend hosting)
  - Render (Backend hosting)
